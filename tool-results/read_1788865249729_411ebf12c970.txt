    12→## Non-Negotiable Rules
    13→1. NO prototypes, NO hardcoded dashboard data, NO fake payment/auth success.
    14→2. Modular Monolith + Selective Workers (NOT microservices).
    15→3. Disabled modules MUST consume ~0 runtime (no workers, no nav, no polling, no connections).
    16→4. Brand: Red (accent only) / Black / White / Neutral. NO teal/green branding.
    17→5. 4 GB RAM sandbox — phase-by-phase, no concurrent heavy processes.
    18→6. Business logic NEVER in React components, page files, or API handlers. Layer: UI → API → Application Service → Domain → Repository.
    19→7. Server-side pagination everywhere. Never load huge datasets into the browser.
    20→8. Backend enforces RBAC. Frontend only reflects/hides.
    21→9. UTC internally, display in tenant/user timezone. Decimal-safe money.
    22→10. Every feature must be a real vertical slice (UI → API → Service → Domain → Repo → DB → Events → Tests → E2E).
